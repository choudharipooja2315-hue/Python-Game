# 🐍💧🔫 Snake, Water & Gun Game (Python)

A command-line based Snake, Water & Gun game built using pure Python.
This project demonstrates basic Python concepts such as conditional statements, loops, user input handling, and random number generation.

 #🎮 Project Overview

Snake, Water & Gun is a simple Python version of the classic hand game (similar to Rock, Paper, Scissors).
The user plays against the computer, and the winner is decided based on predefined rules.

# 🛠️ Technologies Used

Python – Core programming language

random module – For computer’s choice

# ✨ Features

🖥️ Runs in command-line / terminal

🤖 Computer generates random choices

👤 User vs Computer gameplay

🔁 Option to play multiple rounds

📊 Displays result (Win / Lose / Draw)

# 🧠 Game Rules

🐍 Snake drinks Water → Snake wins

💧 Water disables Gun → Water wins

🔫 Gun kills Snake → Gun wins

Same choice → Draw
